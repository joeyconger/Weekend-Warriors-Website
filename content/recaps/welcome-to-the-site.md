This is a placeholder recap so the Recaps page isn't empty. Every file in
`content/recaps/` becomes a post here automatically — just add a new
`.md` file with the same frontmatter shape (`title`, `date`, `excerpt`)
and write the recap underneath it in plain markdown.

## How to add a real one

1. Copy this file to something like `content/recaps/2026-week-01.md`.
2. Update the frontmatter — `title`, `date` (used for sorting, newest first),
   and a one-line `excerpt` for the list page.
3. Write the recap body in markdown below the `---`.

That's it — no build step, no CMS login, just a file in the repo.
