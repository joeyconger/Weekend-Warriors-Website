This is the same `content/recaps/` folder as weekly recaps — the only
difference is `category: "analysis"` in the frontmatter, which sorts it
into the "Analysis" section instead of "Weekly Recaps" on this tab.

Use this category for anything longer-form than a single week's recap:
midseason power rankings, a trade grade, a "who's actually good" trend
piece, playoff picture breakdowns, whatever. Same markdown format as
everything else — just add the `category: "analysis"` line.

## A rough template

**Power Rankings, Week N**

1. Team Name — one line on why they're here
2. Team Name — ...

Or for a trade grade: lay out who gave up what, who "won" it early, and
back it up with actual points-since-the-trade if you want (the
Storylines tab already computes that automatically for recent trades —
worth checking there for real numbers to cite here).
